CIRCUIT QUEST - LEVEL 1 HUTAN SENSOR

Terrain: Both sheets 256x128 pixels, 8 columns x 4 rows, each tile 32x32 px, no margin or spacing. Import each as a tilemap atlas. Transparent blank slots at R1C8 and R2C8.

Props: Separate PNGs with native fixed frame canvases. Animated sequences also have horizontal *_frames.png strips. Use frame size 32x32 for all props. Animated hazards have idle/warning/active or off/warning/active states. Set animations in GDevelop or switch separate PNG sprites by events.

Backgrounds: 1536x384 PNG parallax layers, use horizontal repeat if needed (visual seams depend on placement). Layers are non-colliding and MUST NOT be imported as tiles.

Layout: Reference only. Ground and platforms are to be rebuilt from terrain tiles.

Important: Assets are procedural pixel art at exact export dimensions, not a direct rasterization of the illustrative concept image.
